## 📋 Tasks Completed
1. **Task 1: Hangman Game** - `hangman.py`
   - Classic word guessing game
   - User ko 6 chances milte hain word guess karne ke liye
2. **Task 2: Stock Portfolio Tracker** - `stock_portfolio.py`

3. **Task 3: Task Automation**  - `git automation`
   - Git & GitHub use karke project manage karna seekha
   - `add`, `commit`, `push` commands use kiye
   - Repository ko GitHub pe host kiya

4. **Task 4: Basic Chatbot** - `chatbot.py`
   - Simple rule-based chatbot
   - User ke greetings aur basic questions ka jawab deta hai
   - Console-based conversation
